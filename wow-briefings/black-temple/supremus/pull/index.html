Supremus

Tonight · Friday, 23 October 2026 · Group 5
Heal the Hateful Strike tanks, stand in the middle

TL;DR

  • Two phases switching every ~minute.
  • Tank phase: same half circle as Naj'entus (G3 left, G5 middle, G4 right). Avoid fire on the ground.
  • Kite phase: Supremus fixates on random players and chases them; volcanoes erupt across the room. Run if it's you, dodge if it's not. Kiting is usually short — the tanks get him back quickly.
  • 15-min enrage.

Affliction Warlock

  • Cast Inferno (Summon Infernal) shortly before the pull
  • DoTs survive phase swaps — keep everything ticking while moving
  • If fixated: run, instants only

Holy Priest

  • Assignment: soakers, main tank or flex (raid healing)
  • Kite phase: soaker healers switch to raid healing

Shadow Priest

  • Instant SW:P/VT + Mind Flay between moves
  • If fixated: run
